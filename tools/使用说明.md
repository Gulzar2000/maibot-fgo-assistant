# FGO小助手本地绑定工具

Windows 10/11 x64，将 `FGO账号绑定工具-便携版.exe` 放到自己可写的文件夹（如下载目录），双击运行，无需安装 Python。

使用普通用户权限运行即可，不需要管理员权限。程序固定在 EXE 同目录的 `.fgo-runtime/` 解包运行环境，并将绑定文件保存到你选择的目录；不使用 AppData，不更改系统权限。启动清单明确指定 `asInvoker`，不会请求提升权限。请勿放入 Program Files 等普通用户不可写的目录。

1. 输入你要使用 FGO小助手的 QQ 号。
2. 选择 FGO 角色所在区服：哔哩安卓、iOS 或享游安卓。
3. 点击“生成二维码并绑定”，选择保存文件的文件夹。
4. 在本机窗口扫码，并在官方页面确认登录。二维码有效期约 180 秒。
5. 完成后生成 `<QQ号>.fgobind`。仅将这个文件私发给管理员，管理员导入后即可使用 `/fgo stat real`。

文件包含加密的 QQ 号、区服和登录凭据，仅对应机器人的导入私钥能解密。工具不会发送 QQ 消息，也不会将账号凭据发送到工具作者或第三方服务器；扫码及角色验证通过官方游戏接口完成。授权和取数可能使正在运行的游戏掉线。

请确认你信任管理员，管理员持有机器人导入私钥，可以使用这份登录授权查询账号。解除绑定请使用 `/fgo unbind`，删除机器人保存的本地副本；这不撤销官方服务器已经发放的授权。

如填错 QQ 号或区服，请重新生成。文件名需保持 `<QQ号>.fgobind`。本工具仅配合生成它的 FGO小助手实例使用，更换机器人导入私钥后需要重新生成文件。

本工具内置 Python、Pillow、qrcode、pycryptodome 和 FGO 协议模块，各组件许可证随内置运行文件保留在 EXE 同目录的 `.fgo-runtime/`。
