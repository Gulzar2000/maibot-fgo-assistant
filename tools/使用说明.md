# FGO小助手本地绑定工具

Windows 10/11 x64，将 `FGO账号绑定工具-便携版.exe` 放到自己可写的文件夹（如下载目录），双击运行，无需安装 Python。

使用普通用户权限运行即可。程序在 EXE 同目录的 `.fgo-runtime/` 解包运行环境，路径过长时改用系统临时目录。绑定文件保存到你选择的目录。请勿放入 Program Files 等普通用户不可写的目录。

1. 输入你要使用 FGO小助手的 QQ 号。
2. 选择 FGO 角色所在区服：哔哩安卓、iOS 或享游安卓。
3. 点击“扫码绑定”或“账密绑定”，选择保存文件的文件夹。享游安卓使用扫码绑定。
4. 扫码时请在约 180 秒内用哔哩哔哩 App 扫码并确认。账密绑定时请在本机工具输入 B 站游戏账号和密码。如果 B 站要求安全验证，请在工具弹出的窗口手动完成。这一步需要 Microsoft Edge WebView2 Runtime。
5. 完成后生成 `<QQ号>.fgobind`。仅将这个文件私发给管理员，管理员导入后即可使用 `/fgo stat real`。

文件包含加密的 QQ 号、区服和游戏登录凭据，仅对应机器人的导入私钥能解密。账密登录和角色验证通过 B 站游戏接口完成，密码不写入绑定文件。安全验证窗口使用极验组件，页面只接收本次验证参数。授权和取数可能使正在运行的游戏掉线。

请确认你信任管理员，管理员持有机器人导入私钥，可以使用这份登录授权查询账号。解除绑定请使用 `/fgo unbind`，删除机器人保存的本地副本；这不撤销官方服务器已经发放的授权。

如填错 QQ 号或区服，请重新生成。文件名需保持 `<QQ号>.fgobind`。本工具仅配合生成它的 FGO小助手实例使用，更换机器人导入私钥后需要重新生成文件。

操作失败时会把时间、失败阶段和脱敏错误信息追加到 EXE 同目录的 `FGO绑定工具-错误.log`。日志不保存账号密码、验证码或游戏授权。

本工具内置 Python、Pillow、qrcode、pycryptodome、WebView2 SDK 和 FGO 协议模块，各组件许可证随内置运行文件解包。
