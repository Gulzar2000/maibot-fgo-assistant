# 手动导入绑定文件

核对私聊发送者 QQ 与文件对应的 QQ 号，然后将收到的 `<QQ号>.fgobind` 原名放到此目录。

该 QQ 下一次调用 `/fgo stat real` 时，插件自动解密并导入到原有 DPAPI 凭据库，无需重启。成功后文件改为 `<QQ号>.imported`，不会再次导入；导入出错会保留原文件并明确报错，不覆盖已有绑定。

`/fgo unbind` 同时删除该 QQ 的 DPAPI 凭据、待导入文件和已导入文件，保留模拟记录。

不要将聊天附件直接自动导入。QQ 号由工具使用者填写，文件加密不证明 QQ 所有权，管理员需要核对发送者。请保留插件 `private/import-private.dpapi`；它受当前 Windows 用户 DPAPI 保护，不能将此私钥分发给工具使用者。
