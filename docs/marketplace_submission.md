## 市场简短介绍

面向 FGO 国服的 QQ 助手，支持模拟抽卡、卡池与活动查询、素材来源、真实出率统计、羁绊挖矿计算及青铜果实兑换。

## 详细介绍

在 QQ 中通过 `/fgo` 指令使用以下功能：

- **模拟抽卡**：十一连、百连、卡池切换、保底，以及个人模拟出率统计。
- **卡池与活动查询**：查看国服当前及未来卡池、活动排期，支持活动关键词和中文别名。
- **素材来源查询**：一张图片汇总常驻 Free 本效率、活动奖励和未来交换券。
- **真实账号统计**：扫码绑定后查询当前 AP、五星出率与评级，并查看历次抓包的出率变化曲线。
- **羁绊挖矿计算**：统计普通羁绊和已喂梦火尚未获得的圣晶石；读取背包梦火库存，单独计算可额外解锁的收益，支持与上次查询对比。
- **青铜果实兑换**：按指定数量兑换，或兑换当前 AP 与树苗允许的最大数量。

支持 `/fgo 帮助`、`/fgo 卡池`、`/fgo 活动`、`/fgo 素材`、`/fgo 真实出率`、`/fgo 羁绊计算`（或 `/fgo 挖矿`）及 `/fgo 种树` 等中文指令。

模拟抽卡和公共查询无需绑定游戏账号。真实账号功能目前仅支持 Windows 下的 QQ 绑定，角色区服支持哔哩安卓、iOS、享游安卓；管理员需自行准备协议参数。登录取数可能使正在运行的游戏掉线，兑换指令会实际消耗 AP 和青铜树苗。

登录凭据通过 Windows DPAPI 按系统用户加密保存，支持解除绑定。公开仓库不包含账号凭据、协议密钥、实例绑定密钥或真实抓包数据。活动预估时间和收益数据以国服实际实装为准。

声明兼容范围：MaiBot 1.0.0～1.3.19、插件 SDK 2.12.0～2.21.0，Python 3.12 起。原作、第三方代码和图像来源保留于 README 与 THIRD_PARTY_NOTICES.md。

## GitHub Release 说明

标题：`v1.4.0 · FGO小助手首次公开发布`

主要功能：

- 模拟抽卡、国服卡池与活动排期查询。
- 素材来源图片汇总。
- 扫码绑定、真实出率统计及历史曲线。
- 羁绊挖矿计算，分别展示已喂梦火待兑现收益与背包梦火潜力。
- 青铜果实兑换及常用中文指令。

细节与修复：

- 羁绊计算排除宝具演出等无图鉴实体，公共数据缓存自动更新。
- 羁绊计算与真实出率抓包分别记录每日查询及重复确认状态。
- 账号操作支持互斥与取消，阻塞处理在线程执行。
- 公开仓库排除本机配置、凭据、密钥、真实截图、运行数据和构建产物。

部署前请阅读 README，安装完整依赖。真实账号功能需 Windows、QQ 及自行准备的协议参数；登录可能使游戏掉线。兑换会实际消耗 AP 和青铜树苗。
